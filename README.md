# MobLimiter

Плагин для **Folia 1.21.11**: снижает нагрузку от скоплений мобов и ограничивает количество сущностей.

## Возможности

- **Заморозка скоплений** — при большой плотности мобы перестают «думать» (`setAware(false)`: AI + патфайндинг). Удар/взаимодействие — мгновенное пробуждение, антифликер-кулдаун. Плотность считается скользящим окном — ферму на границе чанков/регионов не «размазать». Мобов НИКОГДА не удаляем.
- **Жители** — с профессией замораживаются (торговля работает), при сбросе профессии просыпаются.
- **Лимиты областей** — мобы, рамки, армор-стенды, картины, транспорт. Яйцо спавна **не тратится** (отменяется сам клик — дюп невозможен), еда при разведении не съедается. Сообщение в чат + звук. Затащенные в переполненную область мобы (поводок/вода/поршни/лодки) не удаляются — они просто замораживаются сканером.
- **Лимиты питомцев** — персистентный счётчик на игрока (`pets.yml` + PDC-теги), обнулить обманом нельзя.
- **Горячие зоны** — `/moblimit zones`: GUI с сортировкой «худшие сверху», жёлтые/красные зоны, клик = телепорт, кнопка обновления. Новая критическая зона — алерт в чат + звук всем с `moblimit.admin`.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/moblimit` | Статус плагина | `moblimit.use` |
| `/moblimit pets` | Свои счётчики питомцев | `moblimit.use` |
| `/moblimit reload` | Перезагрузка конфига | `moblimit.admin` |
| `/moblimit zones` | GUI горячих зон | `moblimit.admin` |

## Сборка

```bash
mvn clean package   # Java 21+, результат: target/MobLimiter-1.0.0.jar
```

Готовый jar также собирается в GitHub Actions (артефакт `MobLimiter-jar`).

## CI

Каждый пуш прогоняет: сборку → запуск настоящего сервера Folia 1.21.11 с плагином → проверку загрузки без ошибок → команды через RCON → функциональный тест лимита (80 попыток спавна → не больше 60 мобов) → корректное выключение.

## Ручная проверка на своём сервере

1. Положите jar в `plugins/`, запустите Folia 1.21.11.
2. Заспавньте 30+ зомби в одной точке — через ~3 сек они замрут; ударьте одного — мгновенно оживёт.
3. Дайте жителю профессию (рабочий блок) — замрёт; сломайте блок — оживёт.
4. При 60+ мобах рядом попробуйте яйцо спавна — сообщение + звук, яйцо осталось; покормите двух коров — еда не тратится.
5. Приручите волков сверх лимита (по умолчанию 8) — отказ; `/moblimit pets` покажет счётчики.
6. `/moblimit zones` (право `moblimit.admin`) — GUI, клик телепортирует к зоне.
